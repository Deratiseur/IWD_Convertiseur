## English

This module allows you to install certain mods designed for BG2EE on IWDEE. It works as follows:

1: Copy the IWDisator and all the BG2EE mods it supports that you want to install into the IWDEE directory (00798).

2: Install the IWDisator. It prepares all the mods.

3: Install all the BG2EE mods you planned. They are ready.

## Français

Ce module vous permet d'installer sur IWDEE certains mods prévus pour BG2EE. Il fonctionne comme ceci :

1 : Copiez dans le répertoire d'IWDEE (00798) le IWDisateur et tous les mods BG2EE qu'il gère que vous voulez installer.

2 : Installez le IWDisateur. Il prépare tous les mods.

3 : Installez tous les mods BG2EE que vous avez prévus. Ils sont prêts.
